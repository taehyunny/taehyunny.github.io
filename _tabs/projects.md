## AI Backend Lab

FastAPI, PostgreSQL, Qdrant, Docker Compose를 이용해 RAG 기반 AI 백엔드 흐름을 실습하는 프로젝트입니다.

- FastAPI API 서버
- PostgreSQL 기반 업무 데이터
- Qdrant Vector DB
- RAG 검색/응답 흐름
- Docker Compose 실행 환경

## 배달 플랫폼

C++ TCP/IP 서버와 MariaDB를 기반으로 배달 주문 흐름을 설계한 팀 프로젝트입니다.

- 서버 세션 관리
- 주문/결제 데이터 흐름
- 주문 시점 데이터 스냅샷
- 서버 측 결제 금액 검증

## 감정 기반 AI 에이전트

웹캠 기반 표정 인식과 LLM 응답을 연결해 개인화 AI 에이전트 구조를 실험한 프로젝트입니다.

- OpenCV
- PyTorch
- FastAPI
- SQLite logging

## 낙상 방지 시스템

실시간 영상 처리와 이벤트 전후 기록 구조를 설계한 프로젝트입니다.

- CircularBuffer
- ThreadSafeQueue
- timestamp sync
- async saving
