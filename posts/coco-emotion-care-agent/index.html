실시간 표정 인식과 LLM 응답을 연결한 감정 케어 AI 에이전트

웹캠 기반 표정 인식, 사용자 선택 보완, 페르소나 기반 LLM 응답, SQLite 로깅과 JSONL 데이터셋 추출까지 연결한 감정 케어 AI 에이전트 개발 기록입니다.

1. 왜 이 프로젝트를 만들었는가

기술이 사람의 감정과 의도를 이해하고 연결하는 도구가 될 수 있다고 생각했습니다. 텍스트만으로는 드러나지 않는 감정이 있고, 사용자가 직접 말하지 않아도 표정이나 선택에서 드러나는 맥락이 있다고 느꼈습니다.

COCO는 이러한 문제의식에서 시작한 AI 감정 케어 시스템입니다. 단순한 챗봇이 아니라, 사용자의 표정과 선택 데이터를 함께 활용해 감정 상태를 이해하고, 그에 맞는 응답과 큐레이션을 제공하는 구조를 만들고자 했습니다.

3. 사용자 흐름

사용자는 웹캠을 통해 표정을 인식받고, 인식된 감정 또는 직접 선택한 감정을 기준으로 페르소나 기반 응답을 받습니다. 이후 사용자의 감정, 상황, 선택 데이터는 SQLite에 저장되고, 추후 학습 데이터로 활용할 수 있도록 JSONL 형식으로 변환됩니다.

웹캠 입력
→ 얼굴/표정 인식
→ 감정 분류
→ 사용자 선택 보완
→ 페르소나 응답
→ SQLite 저장
→ JSONL 데이터셋 추출

4. 핵심 기능

4-1. 실시간 표정 인식

웹캠에서 입력된 프레임을 OpenCV로 처리하고, PyTorch 기반 ResNet18 모델을 활용해 사용자의 표정을 감정 상태로 분류했습니다.

주요 기능은 다음과 같습니다.

  • 웹캠 기반 실시간 프레임 입력
  • 얼굴 영역 감지
  • ResNet18 기반 감정 분류
  • 감정 인식 결과를 UI 흐름과 연결

4-2. 사용자 선택 기반 보완 구조

AI가 표정을 명확히 읽지 못하거나 감정 분류 결과가 불확실한 상황을 고려해, 사용자가 직접 감정을 선택할 수 있는 흐름을 추가했습니다.

이는 AI의 단일 판단에 모든 책임을 맡기기보다, 사용자가 마지막 맥락을 보완할 수 있도록 설계한 구조입니다.

주요 기능은 다음과 같습니다.

  • 감정 인식 실패 시 사용자 직접 선택
  • Angry / Embarrassed / Happy / Hurt 등 감정 선택지 제공
  • AI 판단과 사용자 선택을 함께 고려한 응답 흐름
  • 오인식 상황에서도 서비스 흐름이 끊기지 않도록 보완

4-3. 페르소나 기반 응답

사용자가 선택한 감정에 따라 서로 다른 페르소나로 응답할 수 있도록 구성했습니다. 단일한 챗봇 응답이 아니라, 사용자가 원하는 대화 방식에 맞춰 피드백을 받을 수 있도록 설계했습니다.

주요 기능은 다음과 같습니다.

  • 감정 상태에 따른 응답 분기
  • 페르소나 기반 메시지 생성
  • 음식 / 음악 등 추천 결과 연결
  • 사용자 상황에 맞는 공감형 응답 제공

5. 시스템 설계

COCO는 표정 인식, LLM 응답, 데이터 저장, 학습 데이터 추출이 하나의 흐름으로 이어지도록 설계했습니다.

Webcam
→ OpenCV Frame
→ Face Detection
→ ResNet18 Emotion Classifier
→ FastAPI / LLM Server
→ Persona Response
→ SQLite Log
→ JSONL Dataset

표정 인식 결과와 사용자 선택 데이터는 단순히 화면 응답에만 사용하지 않고, SQLite에 저장해 이후 모델 미세조정에 활용할 수 있도록 구성했습니다.

JSONL 데이터는 다음과 같은 구조를 목표로 했습니다.

Instruction
→ 사용자의 감정과 상황을 기반으로 응답 요청

Input
→ 감정 상태, 사용자가 입력한 상황, 선택 데이터

Output
→ 페르소나 기반 응답 또는 추천 결과

6. 내가 맡은 역할

실시간 감정 인식 및 LLM 연동 흐름을 담당했습니다. 웹캠 프레임에서 감정을 추출하고, 그 결과를 FastAPI/LLM 응답 흐름과 연결하는 부분에 집중했습니다.

또한 AI 감정 인식이 실패하거나 불확실한 상황을 고려해, 사용자가 직접 감정을 선택할 수 있는 보완 구조를 설계했습니다.

7. 개발 중 겪은 문제와 해결 과정

문제 1. AI가 표정을 명확히 인식하지 못하는 상황

웹캠 환경, 조명, 얼굴 각도에 따라 AI가 표정을 명확히 인식하지 못하는 경우가 있었습니다. 감정 케어 서비스에서 잘못된 감정 판단은 사용자 경험에 직접적인 영향을 줄 수 있다고 판단했습니다.

이를 해결하기 위해 AI가 표정을 명확히 읽지 못했을 때 사용자가 직접 감정을 선택할 수 있도록 보완 흐름을 추가했습니다.

결과적으로 AI 단일 판단에 의존하지 않고, 사용자의 선택을 함께 반영하는 구조로 서비스 흐름을 유지할 수 있었습니다.

문제 2. 감정 데이터가 응답 후 사라지는 문제

감정 인식과 응답 생성만 수행하면, 이후 어떤 감정에서 어떤 응답이 나왔는지 검토하기 어렵습니다.

이를 해결하기 위해 SQLite에 감정, 상황, 선택 데이터, 응답 결과를 저장하고, 향후 학습 데이터로 변환할 수 있도록 JSONL 추출 흐름을 구성했습니다.

8. 배운 점

이 프로젝트를 통해 AI 서비스에서는 모델의 예측 결과만큼이나, 사용자가 마지막 맥락을 보완할 수 있는 흐름이 중요하다는 것을 배웠습니다.

특히 감정처럼 민감한 영역에서는 AI가 모든 판단을 확정적으로 내리는 구조보다, AI 추천과 사용자 선택이 결합된 구조가 더 안정적일 수 있다고 느꼈습니다.

다음 단계에서는 다음을 보완하고 싶습니다.

10. 회고

COCO는 단순히 표정을 인식하는 프로젝트가 아니라, 표정 인식 결과를 LLM 응답과 데이터 파이프라인으로 연결한 AI Agent 프로젝트였습니다.

이 프로젝트를 통해 AI 서비스 개발자는 모델만 다루는 사람이 아니라, 입력 데이터, 사용자 보완 흐름, 응답 생성, 저장 구조까지 함께 설계해야 한다는 점을 배웠습니다.
