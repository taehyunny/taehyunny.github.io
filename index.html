ai-blog-agent

내 문서와 프로젝트 경험을 AI 기술블로그 글로 바꾸는 개인 Agent

메모, README, 공모전 자료, 기술 학습 기록을 분석해 문제 정의, 데이터 흐름, AI 적용 방식, 구현 과정, 한계와 다음 개선 방향이 드러나는 포트폴리오형 Markdown 글로 재구성합니다.

Project Snapshot

목표
개인 문서를 AI 서비스 개발자 포트폴리오 글로 변환
입력
Markdown, TXT 메모와 공모전 자료
출력
GitHub Pages, Velog, Tistory로 옮길 수 있는 Markdown 초안
상태
Python MVP, mock LLM 모드, 샘플 출력 생성 완료

왜 만들었는가

학습 기록과 공모전 준비 문서는 시간이 지나면 단순 기록으로 흩어지기 쉽습니다. 이 프로젝트는 “무엇을 공부했다”가 아니라 “어떤 문제를 발견했고, 어떤 데이터와 AI 시스템으로 해결하려 했는가”를 중심으로 글을 다시 구성합니다.

시스템 구조

1. 문서 수집

input_docs/ 안의 Markdown, TXT 파일을 읽고 빈 문서와 지원하지 않는 확장자를 걸러냅니다.

2. 정보 추출

문제 정의, 데이터, 기술, AI 적용 방식, 실패, 한계, 다음 개선 방향을 항목별로 정리합니다.

3. 글 생성

고정 템플릿에 맞춰 기술블로그 Markdown을 만들고, 누락된 정보는 리뷰 질문으로 분리합니다.

python src/main.py

input_docs/
  sample_project_memo.md
  sample_contest_note.md

output_posts/
  generated_index.md
  review_questions.md
  2026-05-25-내-문서를-ai-기술블로그-글로-바꾸는-개인-agent-만들기.md

결과물과 포트폴리오 의미

  • LLM 호출부와 문서 처리 로직을 분리해 mock 모드와 실제 API 모드를 모두 고려했습니다.
  • RAG, Streamlit UI, GitHub 자동 커밋, 블로그 API 연동을 나중에 붙일 수 있도록 모듈 경계를 나눴습니다.
  • AI가 글을 완전히 대신 쓰는 구조가 아니라, 사람이 검토해야 할 질문을 남기는 Human-in-the-loop 구조를 사용합니다.
