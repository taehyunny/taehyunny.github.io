전략기획 관점에서 업무 프로세스, 데이터 구조, AI 자동화 시스템을 설계하고 기록합니다.

회사의 업무 흐름은 요청, 검토, 승인, 실행, 기록이 연결될 때 안정적으로 운영됩니다. 이 블로그는 내부 결재 구조, 문서 체계, 파일 관리 방식, 데이터 기반 의사결정, AI 자동화를 하나의 업무 시스템 관점에서 정리하는 포트폴리오형 기록입니다.

단순히 기술을 구현했다는 기록보다, 어떤 업무 문제가 있었고 어떤 프로세스와 데이터 구조로 해결하려 했는지, 그리고 AI가 어디까지 자동화하고 사람이 어디에서 검토해야 하는지를 남깁니다.

관심사: 전략기획, 업무 프로세스 설계, 내부 시스템 기획, 문서/결재 구조, 데이터 기반 의사결정, AI 자동화, 공공데이터 기반 서비스 기획.

Work Systems

업무 요청과 승인 흐름

요청서, 검토 기준, 승인 단계, 처리 이력을 연결해 누가 무엇을 결정했는지 남기는 구조를 고민합니다.

문서와 파일 관리 체계

자료 요청, 산출물 보관, 버전 관리, 담당자 확인을 업무 시스템 안에서 추적 가능한 형태로 정리합니다.

Business Planning

공공데이터, 정부사업, 내부 운영 데이터를 기반으로 서비스 아이디어를 구체화하고, 실행 가능한 MVP 범위와 운영 지표를 설계하는 과정을 기록합니다.

AI Automation

AI는 모든 판단을 대신하는 도구가 아니라, 반복 문서 정리, 정보 추출, 초안 작성, 검토 질문 생성처럼 업무 시간을 줄이고 사람이 더 중요한 판단에 집중하도록 돕는 도구로 봅니다.

Data & Process

업무 데이터가 의사결정으로 이어지려면 입력 기준, 처리 절차, 저장 위치, 검토 책임이 명확해야 합니다. 이 블로그는 데이터와 프로세스를 함께 설계하는 관점으로 프로젝트를 정리합니다.
